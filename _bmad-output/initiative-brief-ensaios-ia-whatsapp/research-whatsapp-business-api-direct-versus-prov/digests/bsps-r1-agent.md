# Digest — 360dialog and Zenvia official offerings — round 1

Researcher digest; official vendor sources only. Accessed 2026-10-27.

- **360dialog eligibility:** Its embedded signup documents Meta Business Portfolio/company information/valid number/HTTPS site requirements; Brazil is not on its blocked-country list. Its site has a Brazil-specific page. **Sources:** https://docs.360dialog.com/docs/hub/embedded-signup ; https://docs.360dialog.com/docs/hub/migrations ; https://360dialog.com/br/pricing . **Publisher/date:** 360dialog, n.d. **Confidence:** high; **class:** eligibility.
- **360dialog price/support:** Regular API is EUR 49 per number per month plus Meta message fees; vendor says no setup fee or extra per-message platform surcharge. It advertises 24/7 human support, first response under four hours, and a Meta escalation channel. **Sources:** https://360dialog.com/br/pricing ; https://360dialog.com/br/integrations . **Publisher/date:** 360dialog, n.d. **Confidence:** high for its advertised terms; **class:** cost/support.
- **360dialog implementation/exit:** Its docs expose API-key-authenticated messaging, templates, media, and webhooks; webhook endpoint must be HTTPS and answer within five seconds. Its migration guide says phone number and templates transfer to another BSP, while message/chat history does not. **Sources:** https://docs.360dialog.com/docs/messaging-api/api-reference/templates ; https://docs.360dialog.com/docs/messaging/media/upload-retrieve-or-delete-media ; https://docs.360dialog.com/docs/messaging/webhook ; https://docs.360dialog.com/docs/hub/migrations/migrate-to-alternate-bsp . **Publisher/date:** 360dialog, n.d. **Confidence:** high; **class:** integration/operations/portability.
- **Zenvia eligibility/setup:** Its official WhatsApp API offering requires Brazil onboarding details including CNPJ and verified Meta Business Manager; Customer Cloud activation asks for Meta admin access, a live HTTPS site, tax document, and dedicated number, with Zenvia team activation. **Sources:** https://zenvia.com/en/whatsapp/ ; https://support.zenvia.com/kb/en/article/455663/integrating-the-whatsapp-channel-zcc . **Publisher/date:** Zenvia, n.d. **Confidence:** high; **class:** eligibility/onboarding.
- **Zenvia pricing:** Public Customer Cloud pricing shows a R$0 Starter software plan and channel packages from R$100/month; the displayed R$100 package includes up to 182 WhatsApp template sends at R$0.55, says the first 1,000 service messages/month are free then R$0.069, and shows R$649 first-month setup while also displaying an activation-free promotion. The FAQ says API messages are billed/intermediated by Zenvia; public pages do not separate Meta's share or establish a standalone API-only plan. **Sources:** https://zenvia.com/precos/ ; https://support.zenvia.com/kb/en/article/600343/perguntas-frequentes-whatsapp-2026 . **Publisher/date:** Zenvia; FAQ created 2026-08-20, updated 2026-10-04; accessed 2026-10-27. **Confidence:** medium for price applicability, high for public package shape; **class:** pricing.
- **Zenvia implementation/support:** Its current Developer Portal uses `/v2` examples while the detailed public OpenAPI reference found is `/v1`; validate current version/Node library before estimating. Customer Cloud webhooks must respond within five seconds; repeated timeouts degrade or deactivate the hook. Brazil support is listed Monday–Friday 08:00–18:00 except national holidays, plan-dependent. **Sources:** https://zenvia.com/en/devs/ ; https://zenvia.github.io/zenvia-openapi-spec/v1/ ; https://support.zenvia.com/kb/en/article/453693/tokens-webhooks-para-usar-nas-apis-zcc ; https://support.zenvia.com/kb/en/article/565407/como-falar-com-o-suporte-tecnico-da-zenvia . **Publisher/date:** Zenvia; support articles updated 2026-02-12 and 2026-04-15; accessed 2026-10-27. **Confidence:** high; **class:** implementation/support.
- **Zenvia portability gap:** Zenvia docs describe migration between BSPs generally, but older Conversion-specific guidance flags possible template loss/bot reset and does not prove the exit process for current Customer Cloud accounts. **Sources:** https://support.zenvia.com/kb/en/article/363720/o-que-e-a-migracao-entre-bsps-provedores-do-whatsapp ; https://support.zenvia.com/kb/en/article/384841/passos-e-condicoes-para-a-migracao-entre-bsps . **Publisher/date:** Zenvia articles updated 2023-08; accessed 2026-10-27. **Confidence:** medium; **class:** portability/evidence gap.

**Screening result:** 360dialog has the clearest public API-only fit and exit procedure but imposes a fixed EUR 49 monthly fee. Zenvia may have a lower BRL Customer Cloud entry package, but the displayed pricing is product-bundle specific and its API-only price/exit path are unclear. No fair weighted total-cost comparison is possible without message volumes/categories and a Zenvia quote.

**Leads:** Ask Zenvia for exact API product, production Starter eligibility, setup fee, category rates, WABA ownership, current `/v2` Node integration, and Customer Cloud exit process. Choose representative message volumes before a precise total-cost comparison.
